# Doo Doo Town the Game!

A 12-month pixel-art promo game for Mt. Washington Sewer & Drain, based on real calls.

Play / install: https://demore88.github.io/doo-doo-town/

Sound effects from ZapSplat (zapsplat.com), used under the ZapSplat license with attribution (see credits in game).

Testers: open the game once with `?dev=1` to show SKIP buttons and the CUTSCENES menu (`?dev=0` turns it off).
